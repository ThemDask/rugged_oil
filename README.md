# newRTS: asymmetric 2D space RTS

> **Status: shelved.** Paused in favour of a simpler classic RTS (separate project). The vision is
> preserved in [docs/design.md](docs/design.md), and milestones M0–M1 are implemented and tested.

A slow, tactical, top-down 2D space RTS: a mothership-centred fleet vs. a slowly expanding alien
swarm. Made with Godot 4.6 (GDScript).

- Open the project: launch Godot and import `game/project.godot`.
- Run tests: `./tools/run_tests.ps1 -Godot <path to Godot console exe>`
- Play (F5 in Godot): left-click / drag to select, Shift to add, right-click to move.
  Camera: WASD/arrows, screen edges, middle-drag, mouse wheel to zoom.
- Docs: [design](docs/design.md) · [architecture](docs/architecture.md) · [data](docs/data.md) · [roadmap](docs/roadmap.md)

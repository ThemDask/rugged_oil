# Rugged Oil

A top-down 2D RTS on a post-apocalyptic desert Earth. A classic RTS at a slower pace, with a mobile
base instead of buildings and expensive, heavily customisable vehicles. Made with Phaser 3 +
TypeScript.

```bash
npm install
npm run dev      # play at http://localhost:8080
npm test
```

- Controls: left-click / drag to select, Shift to add, right-click to move. Camera: WASD/arrows,
  screen edges, middle-drag, mouse wheel to zoom. Esc: menu.
- Docs: [high-level design](docs/high-level-design.md) · [low-level design](docs/low-level-design.md) · [roadmap](docs/roadmap.md)
